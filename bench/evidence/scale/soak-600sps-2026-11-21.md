# Soak: 620 spans/s x 5 min, zero loss, 2026-11-21 (run soak1)

Setup: current develop build (a7eb693, includes boot-time span_stats fix), Postgres storage,
single box (small sandbox, 2 GB RAM). Load: bench/scale/loadgen.js direct to intake,
50 hosts, 10 services, 100 traces/s (~620 spans/s), 102 logs/s, high-cardinality metric
(2,000 customer ids every 10 s), host metrics every 15 s per host.

## Results (loadgen final summary in soak-600sps-2026-11-21.loadgen.log + DB counts)
- spans: 186,223 sent / 186,223 stored - exact
- logs: 30,586 sent / 30,586 stored - exact
- metric points: 68,000 sent / 68,000 stored for sent metrics - exact
  (scale.orders.placed 60,000 + host metrics 8,000; a further 10,000 rows tagged with the run are
  intake-normalized host metrics such as system.cpu.user, generated at intake per the mapping
  documented in artifacts/api-server/src/intake/otlp.ts, not duplicated sent data)
- intake requests: 2,450, errors: 0
- intake latency over the run: p50 16-21 ms, p99 71-413 ms (p99 settled to ~70-135 ms after warmup)

Caveats: 5-minute window on a small shared sandbox; this complements, not replaces, the 10-minute
2,410 spans/s single-box result in bench/scale/SCALE-RESULTS.md (which ran on 4 vCPU/11 GB).
