# License and security audit

Licenses, known vulnerabilities, secrets, third-party code and trademarks for the whole repository. Last run on
November 16, 2026, on the current tree (Monitoring Agent on OpenTelemetry Collector 0.165). CI repeats the vulnerability
and secret checks on every pull request.

## Summary

| Area | Result |
| --- | --- |
| Monitoring license | Apache-2.0 (`LICENSE`, `NOTICE`) for the server, UI, agent and both libraries. |
| Dependency licenses | All permissive or weak copyleft (MPL-2.0). No GPL, AGPL, SSPL, BUSL or other license that restricts redistribution. Full list in `THIRD_PARTY_LICENSES.md`. |
| Known vulnerabilities, server and UI | 0 (`pnpm audit --prod`). |
| Known vulnerabilities, Node library | 0 (`npm audit --omit=dev`). |
| Known vulnerabilities, Python library | 0 (`pip-audit`). |
| Known vulnerabilities, agent | 0 in code the agent calls or imports. 1 advisory in a required module whose affected code is never called (`govulncheck`). |
| Secrets | None. gitleaks over the full git history finds nothing; three deliberate fake credentials in redaction tests are allowlisted in `.gitleaksignore`. |
| Copied third-party code | Protobuf definitions from Datadog's agent-payload (BSD-3-Clause) and datadog-agent (Apache-2.0), and from opentelemetry-proto (Apache-2.0). Attributed in the source files, with the BSD-3 text and copyright in `NOTICE`. |
| Trademarks | "Datadog" appears only to describe compatibility (migration guide, the `datadog_compat` setting, intake routes for Datadog's open-source agent and tracers). No Datadog logo or brand asset. Non-affiliation statement in `README.md` and `NOTICE`. |

## Licenses

| Component | Production dependencies | Licenses |
| --- | --- | --- |
| Server and web UI | 156 | MIT 128, ISC 20, BSD-3-Clause 4, Apache-2.0 2, MIT AND ISC 1, Unlicense 1 |
| Node.js library | 170 | Apache-2.0 85, MIT 60, BSD-3-Clause 10, BlueOak-1.0.0 8, ISC 7 |
| Python library | 18 | Apache-2.0, BSD, MIT, PSF-2.0 |
| Monitoring Agent | 369 Go packages | Apache-2.0 254, MIT 61, BSD-3-Clause 40, MPL-2.0 10, ISC 2, BSD-2-Clause 2 |

- **MPL-2.0** (HashiCorp modules in the agent, such as consul/api and golang-lru) is file-level copyleft. Monitoring ships
  them unmodified; each agent release includes `monitoring-agent-THIRD_PARTY_NOTICES.txt` with every compiled module's
  license and notice files (generated by `agent/notices.sh`), plus the upstream NOTICE files of
  opentelemetry-collector-contrib and datadog-agent.
- **Server image and web UI** bundle their npm dependencies; `scripts/third-party-notices.mjs` writes their license
  texts to `THIRD_PARTY_NOTICES.txt`, served by every install at `/THIRD_PARTY_NOTICES.txt`.
- **BlueOak-1.0.0** (Node library) is permissive and compatible with Apache-2.0.
- **ClickHouse** (optional storage) is a separate Apache-2.0 server reached over HTTP; it is not bundled.

## Third-party code

- `artifacts/api-server/src/intake/proto.ts`: protobuf message definitions needed to decode the Datadog Agent's
  payloads. `MetricPayload` and `SketchPayload` come from Datadog's agent-payload (BSD-3-Clause, Copyright (c) 2017,
  Datadog, Inc.; full text in `NOTICE`). The trace messages come from datadog-agent (Apache-2.0).
- `artifacts/api-server/src/intake/otlp.ts`: OTLP message definitions from opentelemetry-proto (Apache-2.0).
- No other file carries a third-party copyright header, and there are no vendored source directories.

## Reproduce

```sh
pnpm audit --prod
pnpm licenses list --prod
(cd sdks/node && npm audit --omit=dev && npx license-checker-rseidelsohn --production --summary)
pip install -e sdks/python pip-audit && pip-audit --skip-editable
bash agent/build.sh
(cd agent/_build && go run golang.org/x/vuln/cmd/govulncheck@latest ./... \
  && go run github.com/google/go-licenses@latest report ./...)
go run github.com/zricethezav/gitleaks/v8@v8.28.0 git --redact .
```
